Sunset City Cover Maker — turn your photos into GTA-style multi-panel cover art, offline in the browser. make.fun bounty entry.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome, load a photo, pick a layout and grade, edit the caption, and export a PNG (1080x1080, 1080x1350, or 1920x1080). Your photos never leave your machine.
